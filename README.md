# 🏷️ Adidas Sales Dashboard (Power BI)

This project visualizes Adidas sales performance using Power BI.

## 🎯 Objectives
- Analyze sales by region, category, and product line  
- Monitor profit margins and top-performing products  
- Identify trends and KPIs for decision-making  

## 🧰 Tools Used
- Power BI  
- Excel  
- SQL Server (for data preparation)  

## 📊 Key Insights
- Most sales come from the West region  
- Running Shoes and Apparel categories have highest profit margin  
- Automated daily data refresh for continuous monitoring
